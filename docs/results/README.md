# Результаты: срез доказательств

Сокращения раскрыты при первом употреблении; [полный словарь](../GLOSSARY.md).

Копии компактных артефактов из `results/` (рабочий каталог в `.gitignore`). Полные логи и все
эпизоды не коммитятся: они воспроизводятся командами из
[интеграционного отчёта](../INTEGRATION_REPORT.md).

| Файл | Что это |
|---|---|
| `summary_series20.csv` | сводка 20 эпизодов: 20/20, Wilson 95 % CI `0.84…1.00`, mean 195.54 с, p95 195.63 с |
| `series_audit_20.csv` | аудит каждого из 20 эпизодов: везде 1 FAIL (`/sensors/imu`), 1 WARN (заглушки) |
| `faults.csv` | пять отказов: три с замером задержки, битая модель и заморозка `/clock` |
| `episode_example.csv` | одна строка эпизода по схеме `docs/EXPERIMENTS.md` |
| `audit_example.json` | снимок аудита контрактов (эпизод 20) |
| `manifest_example.json` | манифест эпизода: commit, id образа, measured_run, результат аудита |

Срез снят 25.11.2026 на ветке `integration/skeleton` (коммит до добавления этого каталога),
Ubuntu 24.04, Docker Engine 29.10.0, образ `capstone-dev:local`.
