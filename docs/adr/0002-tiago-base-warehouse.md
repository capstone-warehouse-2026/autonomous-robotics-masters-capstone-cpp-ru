# ADR 0002: робот TIAGo Base и мир склада

Сокращения раскрыты при первом употреблении; [полный словарь терминов](../GLOSSARY.md).

ADR (Architecture Decision Record — запись об архитектурном решении). Статус: принято командой; числовые ограничения робота фиксируются в неделю 2, как требует [PROJECT.md](../PROJECT.md).

## Выбор робота

[PROJECT.md](../PROJECT.md) требует дифференциального робота радиусом 0.25 м со скоростью до 0.6 м/с и ±1.2 рад/с, wheel odometry, IMU (Inertial Measurement Unit — инерциальный измерительный модуль), 2D LiDAR (Light Detection and Ranging — лазерный дальномер) и RGB-D (Red, Green, Blue and Depth — цветное изображение и карта глубины) камерой. Среди стандартных роботов Webots R2025a ближе всего TIAGo Base — модель платформы PAL Robotics PMB2, известной складской и исследовательской базы, на которой отлаживают Nav2 (Navigation 2 — стек навигации ROS 2).

| Робот Webots | Привод | Размер | Скорость | Почему не выбран |
|---|---|---|---|---|
| **TIAGo Base** | дифференциальный | круг, радиус 0.272 м | до 1.0 м/с | — |
| Pioneer 3-DX | дифференциальный | 0.46 × 0.38 м | до 1.2 м/с | некруглый, нет IMU и лидара, только сонары; модель только для Webots |
| TurtleBot3 Burger | дифференциальный | радиус ≈0.1 м | 0.22 м/с | медленнее требуемых 0.6 м/с |
| iRobot Create | дифференциальный | радиус 0.17 м | 0.5 м/с | медленнее 0.6 м/с, нет лидара |
| KUKA youBot | mecanum (всенаправленный) | 0.58 × 0.38 м | до 0.8 м/с | не дифференциальный, прямоугольный |
| MiR100 | дифференциальный | 0.89 × 0.58 м | до 1.5 м/с | почти вдвое больше заданного |

У TIAGo Base уже есть датчики положения колёс, акселерометр, гироскоп и InertialUnit, свободные `lidarSlot` (для Hokuyo URG-04LX или Sick TIM551) и `bodySlot` (для RGB-D камеры). Модель распространяется по лицензии Apache 2.0.

## Решение

- Мир — [simulation/worlds/warehouse.wbt](../../simulation/worlds/warehouse.wbt): склад 20 × 20 м со стенами 2.5 м, четыре ряда стеллажей ([WarehouseRack.proto](../../simulation/protos/WarehouseRack.proto)) с проходами 2.1 м и поперечным проходом у x = −1 м, зона поддонов и ящиков на востоке, шесть станций (жёлтые метки 1.2 × 1.2 м), свободные ящики в периметральных коридорах. Робот `tiago_base` стартует в (−8, 0) лицом к +x.
- Управление — пакет [capstone_sim](../../ros2_ws/src/capstone_sim): плагин `webots_ros2_driver` `capstone_sim::DiffDrive`, единственный потребитель `/cmd_vel` (`geometry_msgs/msg/TwistStamped`) в симуляции. `linear.x` и `angular.z` переводятся в скорости двух колёс (радиус 0.0985 м, база 0.4044 м — из TiagoBase.proto, параметры в [tiago_base.urdf](../../ros2_ws/src/capstone_sim/resource/tiago_base.urdf)); при превышении предела мотора оба колеса масштабируются одинаково. Без свежей команды дольше 300 мс по steady clock или при NaN (Not a Number — специальное значение «не число»)/Inf (Infinity — специальное значение бесконечности) колёса останавливаются — это driver watchdog из [INTERFACES.md](../INTERFACES.md).
- Стандартные модели и текстуры Webots, которые использует мир, хранятся в репозитории ([simulation/webots_assets](../../simulation/webots_assets/README.md)): ни сборка, ни запуск ничего не скачивают. Встроенный загрузчик Webots на части сетей обрывает параллельные соединения с GitHub и оставляет мир без моделей.

Проверено в симуляции: `linear.x` 0.3 м/с даёт 0.30 м/с вперёд без поворота; `angular.z` 0.5 рад/с — около 0.45 рад/с против часовой; предельная команда `(0.6 м/с, −1.2 рад/с)` — около 0.45–0.5 м/с и 1.1 рад/с (проскальзывание и момент моторов); после прекращения команд робот останавливается.

## Что команда закрывает в неделю 2

- Радиус 0.272 м вместо 0.25 м из постановки: зафиксировать footprint, запас и ограничения скорости и ускорения с учётом того, что на предельных командах робот недобирает 10–20% скорости.
- G1 добавляет 2D LiDAR в `lidarSlot`, RGB-D камеру в `bodySlot`, публикацию IMU и wheel odometry под именами из контракта, ground truth (`/evaluation/ground_truth`) и контакты для evaluator через Supervisor API (Application Programming Interface — программный интерфейс).
