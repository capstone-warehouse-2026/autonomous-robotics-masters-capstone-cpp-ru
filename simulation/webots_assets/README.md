# Стандартные ресурсы Webots R2025a

Сокращения раскрыты при первом употреблении; [полный словарь терминов](../../docs/GLOSSARY.md).

Копии файлов из [репозитория Webots](https://github.com/cyberbotics/webots/tree/R2025a) (тег R2025a) по тем же путям `projects/...`: PROTO, модели и текстуры, которые используют миры из `simulation/worlds`. В архиве Webots их нет — Webots скачивает их с GitHub при открытии мира. При сборке образа симулятора эти файлы кладутся в кэш Webots, поэтому ничего не скачивается ни при сборке, ни при запуске, и у всех одинаковые файлы.

Файлы не редактировать вручную. После добавления в мир новых стандартных объектов обновить набор:

```bash
scripts/update_webots_assets.sh
```

Скрипт один раз скачивает официальный архив ресурсов (693 МБ, хранится в `.cache/`), загружает каждый мир без сети и копирует сюда ровно те файлы, которые Webots прочитал. Лицензия файлов — [Webots assets license](https://cyberbotics.com/webots_assets_license) Cyberbotics Ltd.: использование вместе с Webots.
